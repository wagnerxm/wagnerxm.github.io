# wagnerxm.github.io

Páginas públicas no endereço `wagnerxm.github.io`. **Não é o código do KM Check** (o app está nas lojas; o código é privado).

- `kmcheck/` — aviso "O KM Check chegou às lojas!" para quem ainda abre o PWA antigo, com a exportação das fotos antigas; página de download, política de privacidade e manual.
- `controlcheck/` — ControlCheck, separado do KM Check desde 26/11/2026 (o endereço antigo `kmcheck/controlmed/` só leva para cá).
- `kmcheck/noblind/`, `kmcheck/ficha-demo/` — avisos de mudança de endereço.
